# SIA SPACE — 한글 개인 홈페이지 (2차 업데이트)

공개 사이트: https://looloosia.github.io/sia-space/

## 이번 업데이트에서 실제로 동작하는 기능
- 한글 중심 반응형 홈페이지
- 활동 상태 선택 및 변경
- 피아노 연습/순공 스톱워치: 시작, 일시정지, 이어서 시작, 종료 후 저장
- 월간 달력, 날짜별 기록, 오늘/월간 연습 시간 집계
- 최근 본 영화·드라마 추가/수정/삭제와 제목 검색
- 사진, 책, 장소, 프로젝트, 음악, 유튜브, 개인 위키, 타임라인 항목 추가/수정/삭제/검색
- 유튜브 링크(일반 영상 주소 또는 youtu.be) 임베드, 이미지 URL 미리보기
- 회원 등급 이름 수정 및 최대 10등급 미리보기
- 페이지별, 개별 기록별 공개 범위 **설정 UI**
- 인스타그램/유튜브/네이버 블로그 링크 버튼과 전화/문자/이메일 버튼
- JSON 파일 내보내기 및 가져오기

## 중요한 제약: 현재는 로컬 체험판
**실제 등급별 보안/비공개 기능은 구현되지 않았습니다.** 페이지에 표시되는 등급 설정은 로컬 미리보기일 뿐, 계정 인증이나 서버 접근 제어를 수행하지 않습니다.

기록, 링크, 연락처, 상태 변경은 `localStorage`에만 저장되므로 변경한 브라우저에서만 보입니다. 다른 기기나 다른 방문자에게 전파되지 않습니다. 이 상태에서 비공개 정보를 등록하거나 실제 연락처를 공개하려 해서는 안 됩니다.

타이머는 시스템 시각 차이로 누적되고, 브라우저를 닫고 다시 열어도 마지막 측정 상태를 복구하지만 실제로 휴식한 시간과 측정 시간을 자동 구분하지 않습니다. 측정 결과를 `종료하고 기록`으로 저장해야 달력에 나타납니다. 날짜는 종료한 날로 기록합니다.

위치 공유는 **기본 비활성화**이며 브라우저 위치 권한도 요청하지 않습니다. 24시간 백그라운드 스마트폰 위치 추적은 일반 웹 브라우저만으로 안정적으로 제공할 수 없습니다.

## 실제 공동 사용을 위해 추가해야 할 것
1. 인증 시스템과 관리자 계정, 초대/차단 및 등급 관리
2. 서버와 DB (예: Supabase), 서버 권한 검사, 접근 정책 및 비공개 데이터 분리
3. 관리자 전용 콘텐츠 관리 화면, 등급 정책 변경 권한
4. 실시간 상태 공유, 연습 시간/달력 동기화, 업로드 기능
5. 스마트폰 위치 수집 동의, OFF 제어, 서버 기록 삭제 및 접근 감사
6. 방명록, Q&A, 댓글, 좋아요, 북마크, 메시지, 커피챗, 회원 검색

서버를 연결하기 전에는 **클라이언트 코드의 숨김 처리만으로 비공개를 구현하면 안 됩니다.**

## 관리와 백업
`#settings`에서 로컬 설정을 관리할 수 있고, JSON 백업 파일은 연락처도 포함하므로 비공개로 보관하세요.

GitHub Pages의 정적 프론트엔드는 유지할 수 있습니다. `index.html`, `styles.css`, `app.css`, `script.js`, `app.js`를 같은 저장소 루트에 두면 됩니다.
