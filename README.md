# SIA SPACE — 초기 디자인 프로토타입

밝은 아이보리 배경과 미니멀한 편집 디자인을 적용한 개인 홈페이지의 첫 화면 프로토타입입니다.

## 실행 방법
- `index.html`을 브라우저에서 열면 됩니다.
- 별도 빌드 도구나 유료 라이브러리는 필요하지 않습니다.
- Google Fonts 연결을 제외하면 정적 파일만으로 동작합니다.

## 현재 포함된 화면
- 홈 / About
- 사진, 책, 장소, 프로젝트, 음악, YouTube 컬렉션 소개
- 개인 위키 및 타임라인 진입 영역
- 커뮤니티 및 Lv.1~Lv.4 권한 안내
- 반응형 모바일 레이아웃

## 아직 연결되지 않은 기능
현재 파일은 시각적·탐색용 프론트엔드 프로토타입입니다. 실제 서비스로 공개하기 전 다음 기능은 서버와 데이터베이스를 연결해야 합니다.
- 회원가입, 로그인, 세션 관리
- 초대 코드와 회원 등급 관리
- 페이지·게시물별 접근 권한 검사
- 게시글, 댓글, 좋아요, 북마크, 방명록, Q&A, 메시지
- YouTube URL 저장 및 임베드
- 이미지 업로드와 영구 저장
- 관리자 대시보드, 검색, 차단, 커피챗 승인

## 보안 관련 중요 사항
등급별 비공개 페이지는 화면에서 메뉴를 숨기는 것만으로 보호할 수 없습니다. 서버/API에서 매 요청마다 로그인 사용자와 등급을 확인해야 합니다. 관리자 비밀번호나 비밀키를 프론트엔드 JavaScript에 넣지 마세요.
